# Katalyst Content

A library for editing and publishing rich content in Ruby on Rails.

Katalyst Content adds a block-based content editor to your application. Content
is composed of typed items — rich text, figures, tables, layout sections, and
your own custom types — arranged in a nested tree. Every change is versioned:
editors work on a draft and publish when ready, with the published version
served to visitors.
